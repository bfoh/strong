# Cinematic V3 production audit — 13 October 2026

The V3 brief replaces the V2 real-time procedural pavilion with a prerendered, frame-controlled architectural film. Existing V2 proof established real camera motion, but its simple procedural geometry did not meet the requested architectural-film quality. Its camera damping also allowed a temporary discrepancy between scroll position and camera position. V3 requires an exact frame index with no numeric scrub delay.

The initial audit found no `blender` command, Blender application in `/Applications`, `.blend` scene, licensed architectural model, render farm connection or delivered film sequence. Installed Chrome can render a consistent technical blocking preview. This is not a Cycles render or a photorealistic visual proof. Six existing conceptual brand artworks are independent stills and must not be interpolated into a supposedly consistent film.

The existing Next.js 15/React 19 app has GSAP 3.15, Three.js, R3F, Sharp and Playwright already installed. No new runtime dependency is needed for the canvas player. The new public experience does not load the old Three/R3F scene. Three is used only by the local blocking-render script. Supabase server code, authentication, admin, listings, lead forms and Storage are retained.

Research is documented separately in [cinematic-reference-research.md](cinematic-reference-research.md). The supplied YouTube video describes an AI/Framer design workflow; no Blender/GSAP lesson is inferred from it. The playlist is unavailable.

The permitted fallback branch of the brief is implemented: complete player architecture, versioned manifest, camera specification, external Blender/export scripts, and an explicitly labelled temporary preview. The photorealistic visual gate and final-film animation gate remain blocked. A local preview integration does not constitute approval of those gates or publication of a final film.
